# Minería · Ciclo de acarreo

**[▶ Abrir simulación](https://luissegurahse.github.io/Synth-Labs/mineria/acarreo-camiones/)** · [Portal](https://luissegurahse.github.io/Synth-Labs/) · [Código](./index.html)

**Modelo:** eventos discretos (minutos). 1 pala y 1 chancador (un camión a la vez), colas FIFO; tiempos de carga/descarga ±30 % aleatorios; acarreo = distancia/velocidad.
**KPIs:** t/h, utilización pala/chancador, colas. **Supuestos:** sin paradas, sin mezcla de material, ruta única.
**Extender:** segunda pala, pendientes, disponibilidad de camiones, costo por tonelada.
