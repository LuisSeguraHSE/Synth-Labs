# Energía · Microrred PV + batería + diésel

**[▶ Abrir simulación](https://luissegurahse.github.io/Synth-Labs/energia/microrred/)** · [Portal](https://luissegurahse.github.io/Synth-Labs/) · [Código](./index.html)

**Modelo:** despacho horario PV→carga→batería (C/2, η 0.95, SOC mín 10 %)→diésel→no servida. 1 día = 240 s sim. Nubosidad aleatoria; diésel 0.28 L/kWh.
**KPIs:** fracción renovable, combustible, costo, energía no servida, PV recortado.
**Supuestos:** sin rampas de generador ni degradación de batería. **Extender:** CAPEX/LCOE, tarifas, arranque/parada diésel.
