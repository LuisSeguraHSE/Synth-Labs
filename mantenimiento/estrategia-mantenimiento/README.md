# Mantenimiento · Correctivo vs preventivo

**[▶ Abrir simulación](https://luissegurahse.github.io/Synth-Labs/mantenimiento/estrategia-mantenimiento/)** · [Portal](https://luissegurahse.github.io/Synth-Labs/) · [Código](./index.html)

**Modelo:** salud 100→0 con vida variable + riesgo aleatorio creciente; cuadrillas limitadas (correctivos con prioridad). 1 s sim = 1 día.
**KPIs:** disponibilidad, fallas, preventivos, costo total. **Supuestos:** reparación restaura a 100 %, sin repuestos.
**Extender:** Weibull calibrado, inventario de repuestos, criticidad por equipo.
