# Agua · Control de nivel PID

**[▶ Abrir simulación](https://luissegurahse.github.io/Synth-Labs/agua/control-nivel-pid/)** · [Portal](https://luissegurahse.github.io/Synth-Labs/) · [Código](./index.html)

**Modelo:** tanque integrador (A=2 m², Qmax=50 L/s), PID con anti-windup, escalón de demanda cada 120 s. Segundos.
**KPIs:** IAE, nivel máximo, salida de bomba. **Supuestos:** sin retardo ni dinámica de bomba.
**Extender:** retardo/ruido de sensor, válvula con saturación de velocidad, cascada, sintonía automática.
